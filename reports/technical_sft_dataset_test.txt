Пользователь: Напиши функцию, которая группирует строки по их первой букве без учета регистра.
Нова:

ANSWER:
Пустые строки можно пропустить, а ключ нормализовать через `casefold`.
```python
from collections import defaultdict

def group_by_first(words):
    groups = defaultdict(list)
    for word in words:
        if word:
            groups[word[0].casefold()].append(word)
    return dict(groups)
```
Функция сохраняет исходные строки в значениях и порядок их поступления.
