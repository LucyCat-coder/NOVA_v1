ANSWER:
Значения аргументов по умолчанию в Python вычисляются один раз при создании функции, а не при каждом ее вызове. Поэтому список, словарь или другой изменяемый объект будет одним и тем же объектом во всех вызовах, где аргумент не передан явно. Изменения сохранятся между вызовами. Обычно используют значение None и создают новый объект внутри функции.

ANSWER:
`docker stop` отправляет главному процессу сигнал завершения и ждет ограниченное время перед принудительной остановкой. `docker kill` по умолчанию прекращает процесс немедленно.
